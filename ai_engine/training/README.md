# Morph Training

Offline training scripts for Morph V1 and V2 XGBoost classifiers.

These scripts are **read-only reference code** — they are NOT used by the inference pipeline.

## Files

- `scripts/train_model_v1.py` — V1 training (Gary Stafford + Deep Voice only)
- `scripts/train_model_v2.py` — V2 training (+ 50K stratified ASVspoof)

## Note

Training code lives in `scripts/` (not here) to preserve the original project structure.
This directory exists for documentation purposes.
